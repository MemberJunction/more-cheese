## The test

- Does the value survive if nobody can travel?
- Conversation-based sessions usually do
- Hands-on sessions usually do not
- We decide per event, not per calendar

> notes: This is the test Communications will describe in Wednesday's public post. Same wording, so staff and members hear one rule.
